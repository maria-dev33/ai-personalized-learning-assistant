# AI Personalized Learning Assistant

## Overview

AI Personalized Learning Assistant is a web application designed to help students and interns learn effectively through personalized study plans, AI-powered question answering, progress tracking, and weak area detection.

## Features

* Personalized Study Plan Generator
* AI Tutor for answering questions
* Progress Tracking
* Weak Area Detection

## Technologies Used

* Next.js
* React
* TypeScript
* CSS
